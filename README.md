# Python To-Do List

Simple command-line To-Do List application built with Python.

## Features
- Add tasks
- View tasks
- Delete a task
- Delete all tasks
- Input validation
- Menu system

## How to run
1. Install Python  
2. Run the file:
   `python To-do-list.py`

## What I learned
- Lists
- Loops
- Functions
- User input handling
- Error handling (try/except)
